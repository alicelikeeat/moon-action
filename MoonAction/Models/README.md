# Character models

Drop a rigged humanoid model here named after a fighter id to ship it with the app,
e.g. `kai.usdz`, `luna.glb`, `nyx.gltf`. Optional `<id>.json`: `{"yaw": 180, "height": 2.15}`.

Supported: `.usdz` `.usda` `.usdc` `.scn` (SceneKit) and `.glb` `.gltf` (GLTFKit2).
Skeletons using Mixamo / AccuRIG / Unity-VRM / Blender `.L/.R` bone names are retargeted
automatically, so every fighting move works on the imported model.

Fighter ids: kai luna rook ivy nyx blaze mira taro zephyr sable orion kira drake aria bram vex rin juno kael nova
